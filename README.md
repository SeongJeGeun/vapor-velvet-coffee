# VAPOR & VELVET — Artisanal Coffee Roasters

A cinematic, scroll-driven web experience for **VAPOR & VELVET**, an artisanal specialty coffee roastery brand.

Live Demo: [https://vapor-velvet-coffee.web.app](https://vapor-velvet-coffee.web.app)

## Features
- **Scroll-Driven Hero Scrubbing**: High-fidelity espresso extraction video tied directly to user scroll progress with normalized lerp smoothing and seek gating.
- **Interactive Sensory Lab (Flavor Finder)**: Real-time barista curator matching beans and extraction parameters to user taste preferences.
- **Signature Bean Showcase**: Dark, medium, and light roast product cards with sensory flavor profiles.
- **48-Hour Fresh Dispatch Protocol & Philosophy**: Transparent roasting and extraction science.
- **Tasting Kit & Subscription Modal**: Responsive order and grind option workflow.

## Technology Stack
- Vanilla HTML5 / CSS3 / JavaScript (No build step, zero framework bloat)
- Google Flow Veo & Nano Banana AI Media Generation
- FFmpeg Keyframe-Optimized Scrub Pipeline (`-g 8`, H.264, FastStart)
- Google Firebase Hosting with Global Edge CDN
